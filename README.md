# SOHO物件探し（京成高砂軸）

居住者：Stitchify CEO（単身）／住居兼事務所。登記はバーチャルオフィスに分離する方針で検討中。

## 結論（2026-09-26 時点）

**1. 登記はバーチャルオフィスに分ける。これが最大の判断。**
「事務所可／SOHO可」と明示されている予算内の物件は、4サイト横断しても**13室**しかない。登記を月1,650円のVOに逃がせば、物件は一般の居住用でSOHO承諾を取るだけになり、候補が**276室**になる。事業用契約だと賃料に消費税10%が乗って総額69,000円の枠が実質62,700円相当まで縮むので、予算面でも有利。自宅を登記するとCEOの住所が公的DBで公開される問題も回避できる。詳細は [docs/virtual-office.md](docs/virtual-office.md)。

**2. 京成高砂 徒歩20分以内に予算内は15室。全部2K〜2DKの築古で、1LDKは1室もない。**
広さ重視の上位はこうなる。

**本命は2つ。**
- **コーポスズキ**（葛飾区細田4丁目・高砂徒歩13分・2DK 35.77m²・66,000円・敷礼ゼロ）— 高砂徒歩圏で唯一「事務所可」明示。SOHO承諾の交渉が不要なのが決定的に強い。SUUMO・HOME'S・スマイティの3サイトに掲載。
- **エステート高砂**（葛飾区高砂6丁目・徒歩11分・2DK 39.74m²・65,000円・敷礼ゼロ・1995年築）— 高砂徒歩圏で最も広く、唯一の新耐震（1981年6月以降）。初期費用も最小。

**3. 部屋数・広さを取るなら葛飾区の外に出る。**
予算内で2LDK以上・45m²超はすべて高砂徒歩圏外。ドミール北国分（矢切徒歩15分・2LDK 59.5m²・65,000円）、中台グリーンテラスB棟（矢切徒歩16分・2LDK 47.74m²・60,000円）、熊木荘（堀切菖蒲園徒歩12分・2K 44.53m²・68,000円）。矢切は江戸川を渡るので高砂まで自転車20分前後。

**4. 1LDKは予算内でほぼ存在しない。** 276室中、1LDKは数室のみで、高砂徒歩圏には0室。同じ予算なら2K・2DKの方が広い部屋が取れるので、間取りの表記にこだわる意味は薄い。

## 未確定

1. 契約名義（鶴さん個人／Stitchify法人）
2. 初期費用の上限。候補には敷礼ゼロの物件があるのでここが決まると優先順位が変わる
3. 必須設備の線引き（バス・トイレ別／独立洗面／2階以上／光回線／駐輪場）。自転車圏で探すなら駐輪場は実質必須
4. 木造アパート可否。予算内はほぼ木造の築古で、オンライン打ち合わせの防音は弱い

## 次のアクション

1. コーポスズキとエステート高砂の2件をまず内見依頼する（掲載サイトから直接問い合わせが最短）
2. 並行して `docs/inquiry-template.md` で地場仲介2〜3社に条件を投げ、非公開物件を出してもらう
3. 一般物件を見るときは「SOHO利用の承諾が取れるか」だけ確認する（登記はVOなので聞かなくてよい）
4. 内見は `docs/viewing-checklist.md` を持って行く

## データの取得方法と範囲

- **SUUMO**：京成高砂・青砥・柴又・新柴又・京成小岩・お花茶屋・京成金町・金町・亀有・堀切菖蒲園・京成立石・四ツ木・小岩・新小岩・市川・市川真間・国府台・矢切の18駅を、賃料7万円以下・1DK〜3LDKで走査
- **LIFULL HOME'S**：葛飾区・江戸川区・足立区・市川市を、管理費込み7万円以下・1DK〜3LDKで全ページ走査
- **アットホーム**：上記13駅を家賃7万円以下で走査。加えて葛飾区・江戸川区・足立区・市川市のSOHO向け特集を全ページ
- **スマイティ**：葛飾区・江戸川区・足立区・市川市の「事務所可(SOHO向け)」を全ページ走査（507室取得、うち予算内143室）

同一住所・同一間取り・同一面積・同一賃料で名寄せし、対象駅への徒歩アクセスがある物件だけを残した。抽出結果のリンクは無作為に10件を実ページで突き合わせて検証済み。掲載は日々入れ替わるので、動くなら早い方がよい。
