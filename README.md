# SOHO物件探し（京成高砂軸）

居住者：Stitchify CEO（単身）／住居兼事務所。登記はバーチャルオフィスに分離する方針。

## 条件と優先順位

| 項目 | 条件 |
|---|---|
| 総額 | 賃料＋管理費で **69,000円以下** |
| 専有面積 | **30m²以上**（必須） |
| エアコン | **設置済みが必須** |
| 築年 | 制限なし。内見で判断 |
| SOHO | 前提条件（順位の材料にしない） |
| 優先順位 | ①総額の安さ ②京成高砂への近さ ③広さ |

該当は **140室**。うちエアコン設置済みが掲載で確認できるのは44室（設備情報を出しているのはLIFULL HOME'Sだけなので、「要確認」でも付いていることは普通にある）。

**本命は住吉コーポ（60,000円・高砂徒歩10分・2DK 32.22m²）。** 全条件を満たすなかで最安。バス・トイレ別、エアコン設置済み、二口コンロ、フローリング。

**次点は栄ハイツ 1階（同額60,000円・青砥徒歩8分／高砂徒歩14分・2K 34.78m²・新耐震）。** 同じ値段で2.5m²広く新耐震だが、高砂までは4分遠い。

**第一秋谷コーポ（50,000円・2K 32.00m²）は1万円安い。** ただし高砂まで徒歩19分（最寄りは新柴又徒歩5分）でエアコンは要確認。この2点が許容できるなら最有力。

**エアコンを最優先するなら全エリアで最安はハウス光苑（46,000円・矢切徒歩10分・2K 30.00m²）。** 高砂までは北総線で2駅・約5分。

### 登記の扱い

「事務所可／SOHO可」明示で30m²以上・予算内は**6室**。登記を月1,650円のバーチャルオフィスに逃がせば、物件は一般の居住用でSOHO承諾を取るだけになり候補は**140室**。事業用契約だと賃料に消費税10%が乗って69,000円の枠が実質62,700円相当まで縮むので予算面でも有利。自宅登記による住所公開も避けられる。詳細は [docs/virtual-office.md](docs/virtual-office.md)。

## データの取得方法と範囲

- **SUUMO**：京成高砂・青砥・柴又・新柴又・京成小岩・お花茶屋・京成金町・金町・亀有・堀切菖蒲園・京成立石・四ツ木・小岩・新小岩・市川・市川真間・国府台・矢切の18駅を、賃料7万円以下・1DK〜3LDKで走査
- **LIFULL HOME'S**：葛飾区・江戸川区・足立区・市川市を、管理費込み7万円以下・1DK〜3LDKで全ページ走査
- **アットホーム**：上記13駅を家賃7万円以下で走査。加えて葛飾区・江戸川区・足立区・市川市のSOHO向け特集を全ページ
- **スマイティ**：葛飾区・江戸川区・足立区・市川市の「事務所可(SOHO向け)」を全ページ走査（507室取得、うち予算内143室）

同一住所・同一間取り・同一面積・同一賃料で名寄せし、対象駅への徒歩アクセスがある物件だけを残した。抽出結果のリンクは無作為に10件を実ページで突き合わせて検証済み。掲載は日々入れ替わるので、動くなら早い方がよい。
