## 2. 未確定（要確認）

1. **法人登記するか** — ここが最大の分岐。SOHO可は住居契約ベースなので登記不可の物件が多い。登記が必要なら「事務所可」物件か、貸主の個別承諾が要る（賃料に消費税10%が乗る／保証金が上がるケースあり）。
2. 契約名義：個人（鶴さん個人）か法人（Stitchify）か。法人契約だと使える物件が減る一方、審査は通りやすい場合もある。
3. 初期費用の上限（敷金・礼金・仲介手数料・保証会社料の総額）。
4. 必須設備の線引き：バス・トイレ別／独立洗面／2階以上／エアコン／光回線導入済み／宅配ボックス／駐輪場（自転車圏で探す場合は駐輪場が実質必須）。
5. 来客（取引先・インフルエンサー等）の有無。あるならエントランスと共用部の見え方も評価軸に入る。
6. 木造アパート可否。予算的には木造が現実的だが、通話・打ち合わせの防音は弱い。

## 3. エリア方針

- **京成高砂 徒歩圏**：総額6万円台で1LDKは相当タイト。1DK・2DKの築古まで広げると現実味が出る。
- **青砥・お花茶屋・堀切菖蒲園**：高砂まで1〜2駅。賃料は高砂と同水準〜やや安。
- **京成小岩・新柴又・柴又**：各停のみで不便な分、賃料が落ちる。高砂まで自転車10〜15分圏でもある（本命候補になりやすい）。
- **葛飾区南部（青戸・細田・奥戸・新宿）**：駅から遠いぶん安い。自転車前提なら狙い目。
- **市川市（国府台・市川・真間）**：江戸川を渡る（市川橋 or 新葛飾橋）。高砂まで自転車20分前後。千葉県で賃料が一段安い。
- **足立区**：高砂から見ると中川を渡って西側。自転車圏に入るのは六町・北綾瀬あたりまでで、通勤動線としては弱め。優先度は最下位。

## 5. 内見・申込時のチェックリスト（SOHO特有）

- [ ] 契約書の使用目的欄が「住居」か「住居兼事務所」か
- [ ] 法人登記の可否（口頭OKでは不可。特約か覚書で残す）
- [ ] 表札・ポストに屋号を出せるか
- [ ] 来客の可否、宅配・資材の受け取り頻度に制限がないか
- [ ] 賃料に消費税がかかるか（事業用扱いだと10%課税）
- [ ] 火災保険が事業使用をカバーするか
- [ ] 回線：光回線の導入状況（棟内設備 or 個別引き込み可否）
- [ ] 電気容量（アンペア数）とコンセント数
- [ ] 昼間の生活音・通話のしやすさ（構造：木造／鉄骨／RC）
- [ ] 駐輪場の有無と料金（自転車圏エリアで探す場合は必須）
