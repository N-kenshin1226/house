### 本命は2件

面積の足切りを外したことで、基準点に近い安い物件が復活した。

- **（名称非公開・葛飾区鎌倉2丁目）42,000円・446m・1DK 24.79m²・エアコン設置済み** — 2km圏で2番目に安く、かつ2番目に近い。この2つを同時に満たすのはこの1室だけ。最寄りは京成小岩 徒歩8分。角部屋・バス・トイレ別
- **清風コーポ 1階 51,000円・567m・2K 24.79m²・エアコン設置済み** — 3番目に近い。バス・トイレ別、エアコン、角部屋。名前と実体がはっきりしていて3サイトに掲載

**広さも要るなら第一秋谷コーポ（50,000円・1,242m・2K 32.00m²）。** ほぼ同額で8m²広く、自転車6分。ただしエアコン要確認。

**距離だけなら コーポマツイ（250m）が最短。** 62,000円・1DK 24.79m²・築63年でエアコン要確認、SUUMOのみ掲載。

「事務所可／SOHO可」明示は**13室**。登記を月1,650円のバーチャルオフィスに逃がせば、物件は一般の居住用でSOHO承諾を取るだけになり候補は**276室**。詳細は [docs/virtual-office.md](docs/virtual-office.md)。

## データの取得方法と範囲

- **基準点からの距離**：国土地理院のジオコーディングAPIで各物件の住所（丁目レベル）を座標化し、東京都葛飾区高砂4-2-24からの直線距離を計算。191件すべて座標化に成功している。丁目の代表点を使うため数十〜百数十mの誤差が乗る
- **SUUMO**：京成高砂・青砥・柴又・新柴又・京成小岩・お花茶屋・京成金町・金町・亀有・堀切菖蒲園・京成立石・四ツ木・小岩・新小岩・市川・市川真間・国府台・矢切の18駅を、賃料7万円以下・1DK〜3LDKで走査
- **LIFULL HOME'S**：葛飾区・江戸川区・足立区・市川市を、管理費込み7万円以下・1DK〜3LDKで全ページ走査
- **アットホーム**：上記13駅を家賃7万円以下で走査。加えて葛飾区・江戸川区・足立区・市川市のSOHO向け特集を全ページ
- **スマイティ**：葛飾区・江戸川区・足立区・市川市の「事務所可(SOHO向け)」を全ページ走査（507室取得、うち予算内143室）

同一住所・同一間取り・同一面積・同一賃料で名寄せし、対象駅への徒歩アクセスがある物件だけを残した。抽出結果のリンクは無作為に10件を実ページで突き合わせて検証済み。掲載は日々入れ替わるので、動くなら早い方がよい。
