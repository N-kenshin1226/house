# 内見・申込チェックリスト

## 申込前に仲介経由で確認（電話・メールで済む）

- [ ] SOHO（住居兼事務所）としての使用に、賃貸人の承諾が取れるか
- [ ] 契約書の使用目的欄は「住居」か「住居兼事務所」か
- [ ] 法人登記は可能か。可能なら契約形態は住居契約か事業用契約か
- [ ] 賃料に消費税がかかるか（事業用扱いなら10%）
- [ ] 表札・ポストへの屋号表示は可能か
- [ ] 来客・宅配の頻度に制限はないか
- [ ] 火災保険が事業使用をカバーするか
- [ ] 初期費用の総額（敷金・礼金・仲介手数料・保証会社料・鍵交換・清掃費）
- [ ] 保証会社の審査要件（個人契約か法人契約か、収入証明の種類）
- [ ] 定期借家かどうか、中途解約の条件、原状回復の範囲

口頭の「大丈夫です」で進めない。特約か覚書に残す。無断で法人登記すると契約違反で退去を求められる。

## 現地で見る

### 仕事ができるか
- [ ] 光回線の導入状況（棟内設備あり／個別引き込み可／不可）
- [ ] 電気容量（アンペア数）とコンセントの数・位置
- [ ] 昼間の生活音。構造（木造／軽量鉄骨／RC）と隣室の気配
- [ ] 通話・オンライン打ち合わせができる静けさか
- [ ] デスクを置ける壁面があるか。窓の向きと日中の明るさ
- [ ] 携帯の電波（室内の奥まで）

### 生活側
- [ ] バス・トイレ別／独立洗面／追い焚き
- [ ] エアコンの有無と年式
- [ ] 洗濯機置き場（室内か室外か）
- [ ] 収納量。資材や在庫を置くなら要
- [ ] 水回りのカビ・サビ、床の傾き・きしみ（築古は必ず）
- [ ] 窓の結露跡、断熱の程度

### 動線
- [ ] 駐輪場の有無・料金・空き（自転車圏で探すなら必須）
- [ ] 高砂までの実測時間（自転車なら実際に走ってみる）
- [ ] 夜道の明るさ
- [ ] スーパー・コンビニ・郵便局・ATM
- [ ] ゴミ出しのルールと集積所の位置

### 築古物件で特に見る
- [ ] 建物の耐震（1981年6月以降の新耐震かどうか。築年から逆算する）
- [ ] 給湯器・配管の年式
- [ ] 共用部の清掃状態（管理の質がここに出る）
- [ ] 前入居者の退去理由（聞けたら聞く）
