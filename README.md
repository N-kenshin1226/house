# SOHO物件探し（基準点：東京都葛飾区高砂4-2-24）

居住者：Stitchify CEO（単身）／住居兼事務所。登記はバーチャルオフィスに分離する方針。

## 条件と優先順位

| 項目 | 条件 |
|---|---|
| 総額 | 賃料＋管理費で **69,000円以下** |
| 専有面積 | **30m²以上**（必須） |
| エアコン | **設置済みが必須** |
| 築年 | 制限なし。内見で判断 |
| SOHO | 前提条件（順位の材料にしない） |
| 優先順位 | ①総額の安さ ②**高砂4-2-24への近さ** ③広さ |

該当は **140室**。距離は国土地理院のジオコーディングによる直線距離で、徒歩・自転車の目安は道のりを直線の1.2倍として換算した概算。

距離の分布：**1km以内は2室だけ**、1.5km以内9室、2km以内19室、3km以内46室。

### 基準点に一番近いのはコーポスズキ（440m）

30m²以上で1km以内はコーポスズキ（440m）と住吉コーポ（892m）の**2室だけ**。

- **★コーポスズキ**（葛飾区細田4丁目・440m・2DK 35.77m²・66,000円・築44年・新耐震・事務所可明示）— 距離が圧倒的。他の候補の3分の1以下。事務所可が明示されているのでSOHO承諾の交渉も不要。バス・トイレ別、二口コンロ。エアコンのみ要確認
- **住吉コーポ**（葛飾区高砂8丁目・892m・2DK 32.22m²・60,000円・築49年）— 6,000円安く、エアコン設置済みが確認できている

**安さ最優先なら第一秋谷コーポ（50,000円・1,242m・2K 32.00m²）。** コーポスズキより16,000円安く、距離は800m遠い（自転車なら3分の差）。年間19.2万円の差なので、ここは本人の感覚次第。

### 登記の扱い

「事務所可／SOHO可」明示で30m²以上・予算内は**6室**。登記を月1,650円のバーチャルオフィスに逃がせば、物件は一般の居住用でSOHO承諾を取るだけになり候補は**140室**。詳細は [docs/virtual-office.md](docs/virtual-office.md)。

## データの取得方法と範囲

- **基準点からの距離**：国土地理院のジオコーディングAPIで各物件の住所（丁目レベル）を座標化し、東京都葛飾区高砂4-2-24からの直線距離を計算。191件すべて座標化に成功している。丁目の代表点を使うため数十〜百数十mの誤差が乗る
- **SUUMO**：京成高砂・青砥・柴又・新柴又・京成小岩・お花茶屋・京成金町・金町・亀有・堀切菖蒲園・京成立石・四ツ木・小岩・新小岩・市川・市川真間・国府台・矢切の18駅を、賃料7万円以下・1DK〜3LDKで走査
- **LIFULL HOME'S**：葛飾区・江戸川区・足立区・市川市を、管理費込み7万円以下・1DK〜3LDKで全ページ走査
- **アットホーム**：上記13駅を家賃7万円以下で走査。加えて葛飾区・江戸川区・足立区・市川市のSOHO向け特集を全ページ
- **スマイティ**：葛飾区・江戸川区・足立区・市川市の「事務所可(SOHO向け)」を全ページ走査（507室取得、うち予算内143室）

同一住所・同一間取り・同一面積・同一賃料で名寄せし、対象駅への徒歩アクセスがある物件だけを残した。抽出結果のリンクは無作為に10件を実ページで突き合わせて検証済み。掲載は日々入れ替わるので、動くなら早い方がよい。
