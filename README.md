# SOHO物件探し（京成高砂軸）

居住者：Stitchify CEO（単身）／住居兼事務所。登記はバーチャルオフィスに分離する方針。

## 優先順位

**①総額の安さ → ②京成高砂への近さ → ③広さ・快適さ。** SOHO利用は前提条件なので順位の材料にはしない。

**この優先順位なら本命は清風コーポ 1階（51,000円・高砂徒歩9分）。** 高砂徒歩圏で2番目に安く、バス・トイレ別＋エアコン＋角部屋で快適さも取れている。24.79m²は狭いが、優先順位の3番目なので許容範囲。

**予算をあと1.5万円積めるならコーポスズキかエステート高砂。** コーポスズキは事務所可が明示されていてSOHO承諾の交渉が不要、エステート高砂は高砂徒歩圏で最も広い39.74m²。どちらも新耐震。

**第一秋谷コーポ（50,000円・2K 32m²）は安さと広さの両取りができる唯一の物件。** ただし最寄りは新柴又で、高砂までは徒歩19分。

### 登記の扱い

「事務所可／SOHO可」明示の予算内物件は4サイト横断でも**13室**。登記を月1,650円のバーチャルオフィスに逃がせば、物件は一般の居住用でSOHO承諾を取るだけになり候補は**276室**。事業用契約だと賃料に消費税10%が乗って69,000円の枠が実質62,700円相当まで縮むので予算面でも有利。自宅登記による住所公開も避けられる。詳細は [docs/virtual-office.md](docs/virtual-office.md)。

## 未確定

1. 契約名義（鶴さん個人／Stitchify法人）
2. 初期費用の上限。候補には敷礼ゼロの物件があるのでここが決まると優先順位が変わる
3. 必須設備の線引き（バス・トイレ別／独立洗面／2階以上／光回線／駐輪場）。自転車圏で探すなら駐輪場は実質必須
4. 木造アパート可否。予算内はほぼ木造の築古で、オンライン打ち合わせの防音は弱い

## 次のアクション

1. 清風コーポ 1階・第一秋谷コーポ・コーポスズキの3件をまず内見依頼する（掲載サイトから直接問い合わせが最短）
2. 並行して `docs/inquiry-template.md` で地場仲介2〜3社に条件を投げ、非公開物件を出してもらう
3. 一般物件を見るときは「SOHO利用の承諾が取れるか」だけ確認する（登記はVOなので聞かなくてよい）
4. 内見は `docs/viewing-checklist.md` を持って行く

## データの取得方法と範囲

- **SUUMO**：京成高砂・青砥・柴又・新柴又・京成小岩・お花茶屋・京成金町・金町・亀有・堀切菖蒲園・京成立石・四ツ木・小岩・新小岩・市川・市川真間・国府台・矢切の18駅を、賃料7万円以下・1DK〜3LDKで走査
- **LIFULL HOME'S**：葛飾区・江戸川区・足立区・市川市を、管理費込み7万円以下・1DK〜3LDKで全ページ走査
- **アットホーム**：上記13駅を家賃7万円以下で走査。加えて葛飾区・江戸川区・足立区・市川市のSOHO向け特集を全ページ
- **スマイティ**：葛飾区・江戸川区・足立区・市川市の「事務所可(SOHO向け)」を全ページ走査（507室取得、うち予算内143室）

同一住所・同一間取り・同一面積・同一賃料で名寄せし、対象駅への徒歩アクセスがある物件だけを残した。抽出結果のリンクは無作為に10件を実ページで突き合わせて検証済み。掲載は日々入れ替わるので、動くなら早い方がよい。
