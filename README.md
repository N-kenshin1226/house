# SOHO物件探し（京成高砂軸）

居住者：Stitchify CEO（単身）／住居兼事務所として使う一般的なSOHO利用。

## 結論（2026-09-26 時点）

1. **「SOHO可」と明示されている物件で、総額69,000円以下・1LDK以上は0件。** 葛飾区・江戸川区・足立区・市川市のSOHO向け特集を全ページ走査して、予算内で1DK以上だったのは3件だけ（最大が京成金町駅徒歩7分の1DK 40.22m² / 54,000円、ただし築97年）。京成高砂駅のSOHOタグ付きは全体で1件のみ、それも14.5万円の3LDK戸建だった。
2. **なので「SOHO可タグで探す」は捨てる。** 一般の居住用物件を予算・間取りで絞り、貸主承諾をSOHO利用について個別に取るのが唯一の現実的なルート。SOHO可は物件の属性ではなく交渉の結果である。
3. **予算内で京成高砂徒歩圏に実在するのは4室、すべて2K〜2DKの築古。** 最有力は徒歩11分・2DK 39.74m²・総額65,000円・敷礼ゼロ・1995年築の1件。1LDKにこだわるなら、葛飾区内の予算内物件はお花茶屋徒歩10分の1LDK 40.00m²（68,000円・敷礼ゼロ）が唯一。
4. **1LDKの数を増やしたいなら市川市に出る。** 市川駅徒歩16分の1LDK 32.05m²（67,000円）など、千葉側は1LDKが予算内に入ってくる。江戸川を渡るので高砂までは自転車20分前後。

## 未確定（決めると候補が変わる）

1. **法人登記するか。** するなら「事務所可」物件か貸主の個別承諾が必要で、賃料に消費税10%が乗り保証金も上がる。予算69,000円だと成立しにくいので、登記だけバーチャルオフィスに分けるのが現実的。
2. 契約名義（個人／法人）。
3. 初期費用の上限。`docs/candidates.md` には敷礼ゼロの物件もあるので、ここが決まると優先順位が変わる。
4. 必須設備の線引き（バス・トイレ別／独立洗面／2階以上／光回線／駐輪場）。自転車圏で探すなら駐輪場は実質必須。
5. 木造アパート可否。予算内はほぼ木造の築古。オンライン打ち合わせの防音は弱い。
